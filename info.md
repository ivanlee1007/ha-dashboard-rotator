# Dashboard Rotator

Rotate Home Assistant Lovelace dashboard views by configured intervals.

## Features

- Per-view seconds
- Pause on interaction
- Pause when page is hidden
- Frontend controller + backend integration architecture
- Optional status card

## Card

```yaml
type: custom:dashboard-rotator-status
```
